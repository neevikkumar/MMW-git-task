# Practical Assignment – Git \& Collaboration Task



## Objective



This task is designed to evaluate:



- Basic Git usage

- Ability to follow instructions

- Problem-solving approach

- Documentation skills

- Attention to detail



---



# Task Instructions



## Step 1 — Fork or Clone Repository



Fork or clone this repository to your local machine.



---



## Step 2 — Create a New Branch



Create a branch using the following naming format:



```bash

yourname-task

```



Example:



```bash

lakshman-task

```



---



## Step 3 — Make Changes



Inside the repository, complete the following tasks.



### A. Create an `about-me.md` File



Create a file named:



```bash

about-me.md

```



The file should include:



- Your name

- College \& department

- Interests

- Why you applied for this internship

- One technology/tool you want to learn this year



---



### B. Improve Something in the Repository



Do **ONE** of the following:



- Improve the README

- Add a useful resource section

- Fix typos

- Improve formatting

- Add a small feature/page

- Improve UI slightly

- Add better documentation



We want to see initiative, not perfection.



---



## Step 4 — Commit Properly



Use meaningful commit messages.



### Good Example



```bash

git commit -m "Added about-me file and improved README formatting"

```



### Bad Example



```bash

git commit -m "update"

```



---



## Step 5 — Push to GitHub



Push your branch to your GitHub repository.



---



## Step 6 — Submit



Submit the following:



- GitHub repository link

- Branch name

- Short explanation of what you changed



---



# Evaluation Criteria



You will be evaluated based on:



- Git usage

- Clean commit practices

- Ability to follow instructions

- Clarity of documentation

- Initiative and creativity

- Repository cleanliness



---



\# Bonus Points



Optional but appreciated:



- Multiple clean commits

- Better README formatting

- Extra improvements

- Proper markdown usage

- Screenshots/GIFs

- Good folder structure



---



# Important Notes



- You are allowed to use Google, but we prefer you not to use any AI models. 

- We are **NOT** testing memorization.

- We are testing your ability to learn, execute, and communicate.
